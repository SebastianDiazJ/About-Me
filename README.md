🌐 Portafolio Personal - Sebastián Díaz Jiménez

Este es mi portafolio web desarrollado en React, donde presento mi experiencia, habilidades, educación y un formulario de contacto.
El diseño es oscuro, minimalista y profesional, con animaciones hechas con Framer Motion y responsive para cualquier dispositivo 📱💻.

✨ Características

⚛️ React como librería principal.

🎨 CSS personalizado con un diseño moderno en tonos azul oscuro y acentos verde/azulado.

🎬 Animaciones suaves con Framer Motion
.

📱 Responsive Design (funciona en PC, tablets y móviles).

📩 Formulario de contacto conectado a Formspree
 con validación y protección contra spam.

📄 Descarga de CV en PDF con un solo clic.

🌍 Scroll suave entre secciones.

🚀 Instalación y ejecución

Clonar el repositorio:

git clone https://github.com/tuusuario/portafolio-react.git
cd portafolio-react


Instalar dependencias:

npm install


Ejecutar en modo desarrollo:

npm start


La aplicación estará disponible en:
👉 http://localhost:3000

📦 Dependencias principales

React

Framer Motion
 – Animaciones

React Icons
 – Iconos modernos

Formspree
 – Backend para el formulario de contacto

Instalación rápida:

npm install framer-motion react-icons
